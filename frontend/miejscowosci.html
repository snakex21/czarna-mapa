Instrukcja kalibracji mapy

Co trzeba znaleźć?

Do poprawnego położenia starej mapy potrzebujesz dwóch narożników po georeferencji:

  • SW — południowo-zachodni narożnik, czyli lewy dolny.
  • NE — północno-wschodni narożnik, czyli prawy górny.

Najprostsza metoda w QGIS

  1. Otwórz QGIS i dodaj starą mapę jako raster.
  2. Dodaj warstwę odniesienia, np. OpenStreetMap, ortofotomapę albo współczesne działki.
  3. Uruchom georeferencer i wskaż punkty wspólne na starej oraz współczesnej mapie.
  4. Użyj przynajmniej 10–15 punktów: skrzyżowania dróg, zakręty rzek, granice działek, charakterystyczne punkty.
  5. Wykonaj transformację/georeferencję i zapisz wynik jako GeoTIFF.
  6. Wejdź we właściwości wynikowej warstwy/rastera i odczytaj zakres/extent:
Minimum X = SW lng
Minimum Y = SW lat
Maximum X = NE lng
Maximum Y = NE lat

Domyślny widok

Center lat/lng ustaw zwykle na środek między SW i NE. Zoom najczęściej 14 dla miejscowości podobnej wielkości do Czarnej.

Po zapisaniu

Podmień mapę JPG/PNG w tym popupie, wpisz współrzędne i kliknij Zapisz kalibrację. Potem otwórz mapę i sprawdź, czy działki pokrywają się z tłem.

JSON / Backup

JSON jest przenośnym formatem danych aplikacji: owner_data_to_import.json, parcels_data.json, genealogia.json, demografia.json, map_config.json.

Pełny backup miejscowości

Wybierz miejscowości i zakres. Backup zapisze paczkę ZIP z metadanymi, JSON, mapą, ikonami oraz opcjonalnie skanami protokołów, zdjęciami historii i bazą roboczą SQLite.

Eksport danych → JSON

Zapisze aktualne dane aktywnej miejscowości do folderu json/ w katalogu miejscowości.

Import JSON → dane aplikacji

Wybierz pliki JSON z backupu. Import nadpisze odpowiednie dane robocze aktywnej miejscowości.
