Wstęp

Ten przewodnik przeprowadzi Cię przez proces instalacji i konfiguracji systemu mapy katastralnej. Instalacja jest prosta i składa się z 3 głównych kroków:

  1. Instalacja PostgreSQL (jednorazowa, ~10 minut)
  2. Pobranie projektu z GitHub (~5 minut)
  3. Uruchomienie launchera i konfiguracja (~5 minut)

Całkowity czas instalacji: 20-30 minut

Wymagania Systemowe

Minimalne wymagania sprzętowe

  • Procesor: Intel Core i3 / AMD Ryzen 3 (2 rdzenie)
  • RAM: 4 GB (zalecane 8 GB)
  • Dysk: 2 GB wolnego miejsca
  • System operacyjny: Windows 10/11, Linux (Ubuntu 20.04+), macOS

Wymagane oprogramowanie

1. Python 3.10 lub nowszy

Sprawdź wersję:

python --version

Pobierz: python.org/downloads

Instalacja Windows: Zaznacz "Add Python to PATH" podczas instalacji!

2. PostgreSQL 14 lub nowszy + PostGIS

Pobierz: postgresql.org/download

WAŻNE: Podczas instalacji zapamiętaj hasło użytkownika postgres

3. Git (opcjonalne)

Pobierz: git-scm.com

Możesz też pobrać projekt jako ZIP z GitHub

Krok 1: Instalacja PostgreSQL

WAŻNE: PostgreSQL to serwer bazy danych. Będzie działał w tle nawet po zamknięciu aplikacji. Podczas instalacji musisz ustawić hasło - ZAPAMIĘTAJ JE!

Windows

  1. Pobierz instalator PostgreSQL z postgresql.org
  2. Uruchom instalator postgresql-XX-windows-x64.exe
  3. Podczas instalacji:
    • Katalog instalacji: C:\Program Files\PostgreSQL\XX (domyślny)
    • Port: 5432 (domyślny)
    • HASŁO: Wpisz i ZAPAMIĘTAJ (np. zapisz w notatniku)
    • Locale: Polish, Poland lub Default locale
  4. Stack Builder: Po instalacji PostgreSQL uruchomi się Stack Builder:
    • Wybierz swoją instalację PostgreSQL
    • Rozwiń Spatial Extensions
    • Zaznacz PostGIS X.X Bundle for PostgreSQL XX
    • Kliknij Next i zainstaluj
Sprawdź instalację:
  1. Otwórz Start Menu → PostgreSQL → SQL Shell (psql)
  2. Naciśnij Enter 4 razy (użyje domyślnych wartości)
  3. Wpisz hasło które ustawiłeś podczas instalacji
  4. Jeśli zobaczysz postgres=# - instalacja OK!

Linux (Ubuntu/Debian)

# Aktualizuj listę pakietów
sudo apt update

# Zainstaluj PostgreSQL i PostGIS
sudo apt install postgresql postgresql-contrib postgis

# Ustaw hasło dla użytkownika postgres
sudo -u postgres psql -c "ALTER USER postgres PASSWORD 'twoje-haslo';"

# Sprawdź status
sudo systemctl status postgresql

macOS

Najłatwiej przez Homebrew:

# Zainstaluj PostgreSQL
brew install postgresql@14

# Zainstaluj PostGIS
brew install postgis

# Uruchom PostgreSQL
brew services start postgresql@14

# Ustaw hasło
psql postgres -c "ALTER USER postgres PASSWORD 'twoje-haslo';"

Krok 2: Pobranie projektu

Opcja A: Git (zalecane)

# Przejdź do folderu gdzie chcesz mieć projekt
cd Desktop

git clone https://github.com/twoja-nazwa/Projekt-Czarna.git

# Wejdź do folderu projektu

Opcja B: Pobierz ZIP

  1. Przejdź do repozytorium na GitHubie
  2. Kliknij zielony przycisk Code
  3. Wybierz Download ZIP
  4. Rozpakuj archiwum do wybranego folderu

Instalacja zależności Python

# Upewnij się że jesteś w folderze projektu
cd Projekt-Czarna

# Zainstaluj wymagane biblioteki
pip install -r requirements.txt

# Jeśli pip nie działa, użyj:
python -m pip install -r requirements.txt
Opcjonalnie: Możesz utworzyć virtual environment:

# Aktywuj (Windows)
venv\Scripts\activate

# Aktywuj (Linux/macOS)
source venv/bin/activate

# Zainstaluj zależności
pip install -r requirements.txt

Krok 3: Pierwsze uruchomienie

Uruchomienie Launchera

# Upewnij się że jesteś w folderze projektu
cd Projekt-Czarna

# Uruchom launcher
python launcher/launcher_app.py
Co się wydarzy przy pierwszym uruchomieniu:

1. Okno konfiguracji PostgreSQL

Launcher zapyta o dane połączenia z PostgreSQL:

  • Host: localhost (pozostaw domyślnie)
  • Port: 5432 (pozostaw domyślnie)
  • Użytkownik: postgres (pozostaw domyślnie)
  • Hasło: Wpisz hasło które ustawiłeś podczas instalacji PostgreSQL

Po wpisaniu hasła launcher automatycznie:

  • Przetestuje połączenie
  • Wyświetli ✓ Połączenie Udane!
  • Zapisze konfigurację do backend/.postgres.env

2. Okno ładowania

Launcher automatycznie:

  • Utworzy bazę mapa_launcher_db (zarządzanie miejscowościami)
  • Utworzy bazę mapa_czarna_db (dane dla miejscowości Czarna)
  • Utworzy miejscowość "Czarna" jako szablon
  • Zmigruje dane z backup/Czarna/
  • Wygeneruje konfigurację
Pierwsze uruchomienie może zająć 1-2 minuty. To normalne - launcher tworzy bazy danych i importuje dane.

3. Główne okno Launchera

Po inicjalizacji zobaczysz główne okno z sekcjami:

  • 📍 Miejscowość: Aktywna miejscowość (domyślnie: Czarna)
  • ⚙️ Operacje Główne: Uruchomienie serwera, migracja danych
  • 🛠️ Narzędzia Deweloperskie: Edytory danych
  • 🌐 Szybki Dostęp: Linki do aplikacji webowej

4. Uruchomienie serwera

  1. Kliknij 🚀 Uruchom Serwer Backend
  2. Poczekaj aż zobaczysz w konsoli: ✓ Running on http://127.0.0.1:5000
  3. Kliknij 🗺️ Mapa Interaktywna w sekcji Szybki Dostęp
  4. Przeglądarka otworzy aplikację webową!
Gratulacje! System działa.

Możesz teraz przeglądać mapę katastralną, dane właścicieli, statystyki i genealogię.

Rozwiązywanie problemów

Problem: "python: command not found"

Rozwiązanie:
  • Windows: Sprawdź czy Python jest w PATH. Reinstaluj z opcją "Add to PATH"
  • Linux/macOS: Użyj python3 zamiast python

Problem: "ModuleNotFoundError: No module named 'flask'"

Rozwiązanie: 
pip install -r requirements.txt

Jeśli nie działa:

python -m pip install flask psycopg2 werkzeug

Problem: "✗ Błąd połączenia z PostgreSQL"

Sprawdź:
  1. Czy PostgreSQL jest uruchomiony? 
    # Windows - otwórz Usługi i szukaj "postgresql"
# Linux
sudo systemctl status postgresql

# macOS
brew services list
  2. Czy hasło jest poprawne? Sprawdź w notatniku gdzie je zapisałeś
  3. Czy port 5432 nie jest zajęty? 
    # Windows
netstat -ano | findstr :5432

# Linux/macOS
lsof -i :5432

Problem: "Port 5000 is already in use"

Rozwiązanie:

Zmień port w ustawieniach:

  1. W Launcherze kliknij ⚙️ Konfiguracja DB
  2. Edytuj plik .env aktywnej miejscowości
  3. Zmień FLASK_PORT=5000 na np. FLASK_PORT=5001
  4. Zapisz i uruchom serwer ponownie

Problem: Launcher się nie uruchamia (Windows)

Rozwiązanie:

Tkinter może nie być zainstalowany. Reinstaluj Python z opcją "tcl/tk and IDLE"

Problem: "Permission denied" przy tworzeniu bazy danych

Rozwiązanie:

Użytkownik postgres musi mieć uprawnienia SUPERUSER:

psql -U postgres -c "ALTER USER postgres WITH SUPERUSER;"

Następne kroki

Poznaj system:

  • Mapa Interaktywna: Przeglądaj działki, rzeki, drogi
  • Baza Właścicieli: Wyszukuj osoby, przeglądaj genealogię
  • Statystyki: TOP 50 właścicieli, ranking działek
  • Panel Administracyjny: Edytuj dane (wymaga hasła)

Dodaj własną miejscowość:

  1. Kliknij ⚙️ Zarządzaj Miejscowościami w Launcherze
  2. Kliknij ➕ Dodaj miejscowość
  3. Wypełnij formularz (nazwa, opis, szablon)
  4. Użyj edytorów aby dodać dane

Backup i Restore:

System automatycznie tworzy backupy w formacie ZIP. Możesz:

  • Eksportować dane miejscowości
  • Przywracać z kopii zapasowej
  • Migrować dane między instalacjami

Wdrożenie produkcyjne (dla gmin)

Dla środowiska produkcyjnego (serwer dostępny publicznie) zalecane są dodatkowe kroki:

1. Serwer dedykowany

  • Ubuntu Server 22.04 LTS lub nowszy
  • Minimum 4 GB RAM, 20 GB dysk
  • Stały adres IP lub domena

2. Nginx jako reverse proxy

# Zainstaluj Nginx
sudo apt install nginx

# Konfiguracja (przykład)
server {
    listen 80;
    server_name mapa.gmina-czarna.pl;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

3. SSL (HTTPS)

# Zainstaluj Certbot
sudo apt install certbot python3-certbot-nginx

# Uzyskaj certyfikat SSL
sudo certbot --nginx -d mapa.gmina-czarna.pl

4. Systemd service

Utwórz plik /etc/systemd/system/mapa-katastralna.service:

[Unit]
Description=Mapa Katastralna Backend
After=network.target postgresql.service

[Service]
User=www-data
WorkingDirectory=/var/www/Projekt-Czarna
Environment="PATH=/var/www/Projekt-Czarna/venv/bin"
ExecStart=/var/www/Projekt-Czarna/venv/bin/python backend/app.py

[Install]
WantedBy=multi-user.target
# Włącz i uruchom
sudo systemctl enable mapa-katastralna
sudo systemctl start mapa-katastralna

5. Zabezpieczenia

  • Firewall: Otwórz tylko porty 80, 443, 22 (SSH)
  • PostgreSQL: Zmień hasło postgres, użyj silnego hasła
  • Admin Panel: Włącz autentykację (Ustawienia Administratora)
  • Backup: Skonfiguruj automatyczne backupy (cron)
